# Required official corpus — IMPORTANT

The assignment requires authoritative documents from CBIC/DGFT: (1) Customs Tariff General Rules for Interpretation, (2) Customs Tariff Chapters 73 and 96 including section/chapter notes, and (3) DGFT export policy schedule for those chapters.

**No official tariff passages are bundled in this starter.** Do not treat this README or generic notes as legal evidence. Obtain the current official documents from CBIC/DGFT, verify publication/version/date, extract text (OCR scanned PDFs), and place clean `.txt` or `.md` files in this directory. Preserve headings, note identifiers and source metadata. Restart/rebuild the service after adding documents. The service intentionally returns no HS code unless official passages can be retrieved and verified.
